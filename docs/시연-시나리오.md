### 컷 05-1 · 기록은 어디서 오나 (0:32-0:42 · 10초) — **에밀리 한**

> **"그 기록은 누가 쓰는데요?"**

**컷 05 와 같은 페이지입니다.** 토글 아래로 스크롤만 내리면 「개인 AI 연결
(MCP)」 칸이 나옵니다 — 화면 전환이 한 번도 없습니다.

1. **`토큰 발급`** → `brd_…` 토큰과 함께 붙여 넣을 명령이 한 줄 나옵니다

   ```
   claude mcp add --transport http bordo http://127.0.0.1:8000/mcp --header "Authorization: Bearer brd_..."
   ```

- **이름을 반드시 넣으십시오.** 대상 판정(`targeting.pick`)이 애매하면
  **아무도 깨우지 않습니다**(의도된 설계입니다)

### ④ 대리인이 유보합니다 — 컷 09 · 13 이 여기서 나옵니다

- 왜 유보하는가 — 의도가 `SCHEDULE` 로 분류되고, 에밀리 한의 설정이
  `allow_schedule_change=False` 라 **LLM 생성 자체를 하지 않습니다**(`policy.check`)
- 기대 발언 — "일정을 미루는 결정은 제가 정할 수 있는 항목이 아닙니다…"
- 이것이 `PendingQuestion` 이 되어 컷 09 의 `답변이 필요해요` 한 건,
  컷 13 의 채팅 한 줄이 됩니다

### 쓰면 안 되는 대사

| 대사 | 왜 |
|---|---|
| `이거 지금 DB 구조에서 구현 가능해요?` (스토리보드 원문) | 시드에 DB · 인덱스 기록이 없습니다. 근거 0건 → 유보 |
| "요즘 어때요?" · "진행 상황 공유 부탁드려요" | `진행`·`상황`·`현황` 은 불용어라 토큰이 안 남습니다 |
| 이름 없이 "이거 언제 돼요?" | 대상 판정이 아무도 안 고릅니다. 대리인이 침묵합니다 |
| "ㅇㅋ", "넵" | 질문이 아니라 판정이 걸러 냅니다 |

### 물어도 절대 안 나가는 것 (보여줄 자리가 있으면)

> "에밀리님 이번 주 개인 일정은 어때요?"

비공개로 표시한 생각(`이번 주 개인 일정이 빠듯합니다`)은 **설정과 무관하게**
막힙니다(`policy.can_disclose`).

## 리허설 — 촬영 전에 한 번만

찍는 순서 그대로 돌려 봅니다.

```
1. (준비) 강태현 로그인 → Discord 연결 → 회의 만들기
2. 에밀리 로그인 → 개인 설정 → 토글 껐다 켜기          ← 컷 05
2-1. 같은 페이지 → 토큰 발급 → AI 에게 "기록해 줘"    ← 컷 05-1
     → 현재 상태에 작업이 한 줄 늘면 성공
3. 홈 → 회의에 참여하지 않아요 → 불참 등록          ← 컷 06
3-1. 민 로그인 → 같은 절차로 불참 등록              ← 컷 06 뒷부분
4. 준비 화면 → 쟁점이 떴는가 · 근거 카드가 붙었는가  ← 컷 07
5. /meeting-start → ②③ 질문      → 둘 다 답하면 성공  ← 컷 08
6.                  ④ 질문       → 유보하면 성공
7. /meeting-end
8. 에밀리 한 → 브리핑 네 칸 · 답변이 필요해요에 답      ← 컷 09
9. 플로우 → 맥락 재생 · 내용 필터 · 화살표 패널      ← 컷 10·11·12
10. 강태현 → 채팅 「개인 대화」 → 그 답이 와 있다     ← 컷 13
```

> **리허설은 한 번만.** 모델 호출에 **하루 한도**가 있습니다(아래).
> 리허설 한 번이 열댓 번을 씁니다.
>
> 리허설 뒤에는 초기화하고 **Discord 스레드도 손으로 지우십시오** — 서버
> 초기화는 Discord 쪽 메시지를 못 지웁니다.

### 모델 한도

이 계정은 모델마다 **하루 50회**, 대부분의 모델이 **분당 3회**입니다. 회의
발언 하나가 여러 번 부르므로 분당 3회짜리로는 대리인이 곧바로 침묵합니다.
그래서 `.env` 의 `OPENAI_MODEL` 을 **`gpt-4.1-mini`** 로 두었습니다.

촬영 중 갑자기 조용해지면 하루 한도를 다 쓴 것입니다. `gpt-4o-mini` 로 바꾸고
백엔드를 다시 띄우면 새 한도로 이어집니다 — 개발 담당에게 말씀하십시오.

## 대리인이 조용할 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 회의 내내 아무 말도 없음 | `OPENAI_API_KEY` · `bot/discord.log` · 웹 `계정` 이 `연결됨` 인지 |
| 슬래시 커맨드에 반응이 둘 | 원격 봇이 아직 켜져 있습니다 |
| 부재자 홈에 회의가 안 보임 | **그 사람 시계로는 내일입니다.** 「회의 시각」 구간을 다시 보십시오 |
| 한 사람의 대리인만 답함 | 나머지 한 명이 **불참 등록**을 안 했습니다 |
| 특정 질문에만 침묵 | 대상 판정이 아무도 안 골랐습니다. **이름을 넣어** 다시 |
| 대리인이 근거 없이 유보만 함 | 컷 05 에서 **토글을 다시 안 켰습니다** |
| 갑자기 전부 조용해짐 | **하루 한도**(모델당 50회). `OPENAI_MODEL` 을 `gpt-4o-mini` 로 |
| "관련 기록을 찾지 못해…" | 질문 낱말이 저장된 제목과 안 겹칩니다. 위 대사표대로 |
| 플로우가 전부 같은 진하기 | 회의 종료 전입니다. `/meeting-end` 를 먼저 |
| `/meeting-start` 자동완성이 빔 | 스레드가 이미 붙은 회의는 안 뜹니다. 회의를 새로 |
| 논쟁점이 안 뜸 | 아직 생성 중입니다(10~20초). `Bordo가 논쟁점을 예상하고 있어요…` |

개발 담당은 백엔드 로그를 같이 보십시오. 봇이 발언을 밀어 넣으면
`POST /internal/v1/discord/messages 200` 이 찍힙니다. **이게 안 찍히면 봇 문제**,
찍히는데 대리인이 조용하면 **판정·정책 문제**입니다.

- **문서 검색은 `icontains`** 입니다. 임베딩은 2차입니다
