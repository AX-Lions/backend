
## 0-3. 회의 시각 — **아무 때나 됩니다**

오늘이든 다음 주든 상관없습니다. 다만 **어디서 불참을 누르는지**가 갈립니다.

| 회의가 언제인가 | 불참 등록하는 곳 |
|---|---|
| 그 사람 기준 **오늘** | 홈 「오늘 일정」의 `회의에 참여하지 않아요` |
| 그 밖 | **`회의 일정`(달력)** 에서 그 날짜의 칸을 눌러 뜨는 팝업의 같은 버튼 |

홈 「오늘 일정」은 보는 사람의 시간대로 하루를 자릅니다. 시차가 다른 팀원끼리는
같은 회의가 누구에겐 오늘, 누구에겐 내일입니다 — **그래서 달력 쪽 진입점이
있습니다.** 홈에 안 보이면 달력으로 가십시오.

4. **`연결됨`** 으로 바뀌면 성공

> DM 이 안 오면 — Discord 서버 설정에서 `서버 멤버가 보내는 DM 허용` 을 켜십시오.

## 0-6. Discord — 서버를 팀에 잇기

Discord 에서 **`/bordo-team-connect`**
→ `이 서버를 'Bordo 시연팀'에 연결했습니다.` 가 뜨면 성공

> `팀의 소유자 또는 관리자만…` 이 뜨면 — **강태현이 아닌 계정으로 0-5 를 했습니다.**
> 강태현으로 로그인한 상태에서 `/bordo-connect` 부터 다시 하십시오.
>
> `팀을 고르라` 고 하면 — 안내에 뜬 id 로 `/bordo-team-connect team_id:<붙여넣기>`

## 0-7. 회의 만들기

1. 홈 「오늘 일정」 오른쪽 위 **`+`**
2. 팝업에 입력
   - 팀 **`Bordo 시연팀`** ← **팀을 먼저 고르십시오** (같은 이름의 프로젝트가
     개발용 시드에도 있습니다)
   - 프로젝트 `글로벌 회의 도구`
   - 제목 **`API 명세 리뷰`**
   - 참여자 **에밀리 한 · 응우옌 민 둘 다** (본인은 목록에 없습니다 — 서버가 넣습니다)
   - 시각은 아무 때나 (0-3 참고)
3. `일정 추가하기` → 홈 「오늘 일정」에 회의가 보이면 성공

# 부록 C. 대사 — 왜 그 문장인가

문서 검색이 아직 임베딩이 아니라 **제목·본문 토큰 일치**입니다. 낱말이 저장된
제목을 비껴가면 근거가 `추측` 으로만 잡혀 유보로 갑니다.

- **② `플로우`·`연결`** → 작업 제목 `플로우 화면 컴포넌트 연결` 에 걸립니다
- **③ `시안`** → 작업 `회의 상세 화면 최종 시안` · 계획 `디자인 시안 8/18 확정` 에 걸립니다
- **④** → 의도가 `SCHEDULE` 이고 에밀리의 `allow_schedule_change=False` 라
  **LLM 생성 자체를 안 합니다.** 그래서 유보가 확정적으로 납니다

## 쓰면 안 되는 대사

| 대사 | 왜 |
|---|---|
| `DB 구조에서 구현 가능해요?` | 시드에 DB 기록 없음 → 근거 0건 |
| "요즘 어때요?" · "진행 상황 공유 부탁드려요" | `진행`·`상황`·`현황` 은 불용어 |
| 이름 없이 "이거 언제 돼요?" | 대상 판정이 아무도 안 고릅니다 |
| "ㅇㅋ", "넵" | 질문이 아니라 걸러집니다 |

## 물어도 안 나가는 것 (보여줄 자리가 있으면)

> "에밀리님 이번 주 개인 일정은 어때요?"

비공개 생각(`이번 주 개인 일정이 빠듯합니다`)은 **설정과 무관하게** 막힙니다.
