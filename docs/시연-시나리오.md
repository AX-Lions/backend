## 대사 — 회의에서 이렇게 물으십시오

문서 검색이 아직 임베딩이 아니라 **제목·본문 토큰 일치**입니다
(`apps/agent/services/skills/search_records.py`). 질문의 낱말이 저장된 제목을
비껴가면 근거가 `추측(inferred)` 으로만 잡혀 유보로 갑니다(`judge.py` R3).

```
① 시작하겠습니다. 오늘은 API 명세를 훑고 남은 일정을 정리하겠습니다.
② 윤서아님 시안 작업 지금 어디까지 됐나요?
③ 디자인이 밀리면 개발도 1주 미뤄야 할 것 같은데,
   윤서아님 쪽에서 1주 연장으로 확정해도 될까요?
```

**각 줄 사이 10초.** 답이 오기 전에 다음 줄을 치면 두 답이 뒤섞입니다.

### ② 대리인이 답합니다 — **이 한 번이 컷 08 입니다**

- 왜 도는가 — `시안` 이 작업 제목 `회의 상세 화면 최종 시안` 과 계획 제목
  `디자인 시안 8/18 확정` 에 **제목으로** 걸려 `direct` 가 됩니다
- 기대 답변 — 70% · 남은 것은 브리핑 패널 · 마감 8월 18일
- **이름을 반드시 넣으십시오.** 대상 판정(`targeting.pick`)이 애매하면
  **아무도 깨우지 않습니다**(의도된 설계입니다)

### ③ 대리인이 유보합니다 — 컷 09 · 13 이 여기서 나옵니다

- 왜 유보하는가 — 의도가 `SCHEDULE` 로 분류되고, 윤서아의 설정이
  `allow_schedule_change=False` 라 **LLM 생성 자체를 하지 않습니다**(`policy.check`)
- 기대 발언 — "일정을 미루는 결정은 제가 정할 수 있는 항목이 아닙니다…"
- 이것이 `PendingQuestion` 이 되어 컷 09 의 `답변이 필요해요` 한 건,
  컷 13 의 채팅 한 줄이 됩니다

### 쓰면 안 되는 대사

| 대사 | 왜 |
|---|---|
| `이거 지금 DB 구조에서 구현 가능해요?` (스토리보드 원문) | 시드에 DB · 인덱스 기록이 없습니다. 근거 0건 → 유보 |
| "요즘 어때요?" · "진행 상황 공유 부탁드려요" | `진행`·`상황`·`현황` 은 불용어라 토큰이 안 남습니다 |
| 이름 없이 "이거 언제 돼요?" | 대상 판정이 아무도 안 고릅니다. 대리인이 침묵합니다 |
| "ㅇㅋ", "넵" | 질문이 아니라 판정이 걸러 냅니다 |

### 물어도 절대 안 나가는 것 (보여줄 자리가 있으면)

> "윤서아님 이번 주 개인 일정은 어때요?"

비공개로 표시한 생각(`이번 주 개인 일정이 빠듯합니다`)은 **설정과 무관하게**
막힙니다(`policy.can_disclose`).

## 대리인이 조용할 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 회의 내내 아무 말도 없음 | `OPENAI_API_KEY` · `bot/discord.log` · 웹 `계정` 이 `연결됨` 인지 |
| 슬래시 커맨드에 반응이 둘 | 원격 봇이 아직 켜져 있습니다 |
| 윤서아 홈에 회의가 안 보임 | **날짜 경계입니다.** 위 시간대 확인 명령을 돌리십시오 |
| 특정 질문에만 침묵 | 대상 판정이 아무도 안 골랐습니다. **이름을 넣어** 다시 |
| 대리인이 근거 없이 유보만 함 | 컷 05 에서 **토글을 다시 안 켰습니다** |
| 갑자기 전부 조용해짐 | **하루 한도**(모델당 50회). `OPENAI_MODEL` 을 `gpt-4o-mini` 로 |
| "관련 기록을 찾지 못해…" | 질문 낱말이 저장된 제목과 안 겹칩니다. 위 대사표대로 |
| 플로우가 전부 같은 진하기 | 회의 종료 전입니다. `/meeting-end` 를 먼저 |
| `/meeting-start` 자동완성이 빔 | 스레드가 이미 붙은 회의는 안 뜹니다. 회의를 새로 |
| 논쟁점이 안 뜸 | 아직 생성 중입니다(10~20초). `Bordo가 논쟁점을 예상하고 있어요…` |

개발 담당은 백엔드 로그를 같이 보십시오. 봇이 발언을 밀어 넣으면
`POST /internal/v1/discord/messages 200` 이 찍힙니다. **이게 안 찍히면 봇 문제**,
찍히는데 대리인이 조용하면 **판정·정책 문제**입니다.
